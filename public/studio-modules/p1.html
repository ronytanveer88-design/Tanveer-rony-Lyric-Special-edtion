API key না থাকলেও prompt, scene, storyboard ও color guide-এর local template generator কাজ করবে। উন্নত AI-ভিত্তিক ফলাফলের জন্য API connection প্রয়োজন।

About this build

এটি CinemaMaster Android project-এর feature structure অনুসরণ করে তৈরি mobile-friendly HTML prototype। AI generation-এর জন্য optional Gemini API connection আছে। এটি এখনো native APK নয় এবং browser-এর বাইরে server/database ব্যবহার করে না।
